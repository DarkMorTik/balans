# Баланс — приватный учёт финансов

Минималистичное приложение для контроля доходов и расходов на iPhone, iPad и Mac.
Работает как PWA: устанавливается на экран «Домой» и запускается как обычное приложение, офлайн.

## Возможности
- Главный экран: баланс месяца, кнопки **Трата** / **Доход**, лента операций по дням, поиск.
- Быстрый ввод: сумма (поддерживает выражения `120+45`), ярлык, описание с подсказками, дата.
- Ярлыки по умолчанию (Продукты, Такси, Торговля, Обмен валюты…) и свои — с эмодзи, цветом и месячным лимитом.
- Мультивалютность с ручными курсами (без интернета).
- Аналитика: неделя / месяц / год, доходы и расходы по дням, расходы нарастающим итогом с прогнозом, доли по ярлыкам, тенденция за 6 месяцев.
- Умный анализатор: необычно крупные траты, растущие категории, мелкие частые «утечки», дубли, подписки, превышение лимитов, прогноз дефицита, норма сбережений.

## Безопасность
- Данные хранятся **только на устройстве** (IndexedDB) и зашифрованы **AES-256-GCM**.
- Ключ шифрования выводится из 6-значного PIN (PBKDF2-SHA256, 600 000 итераций) или из passkey Face ID / Touch ID (WebAuthn PRF, iOS 18+).
- Блокировка при сворачивании, экран скрывается в переключателе приложений, пауза после 5 неверных PIN.
- Строгая Content-Security-Policy: никаких внешних скриптов и сетевых запросов, ноль зависимостей, ввод выводится без `innerHTML`.
- Резервная копия — файл, зашифрованный отдельным паролем.

## Установка на iPhone / iPad
1. Откройте адрес сайта (GitHub Pages) в **Safari**.
2. Нажмите «Поделиться» → **«На экран „Домой“»**.
3. Запускайте с иконки «Баланс». После первого запуска работает без интернета.

На Mac: Safari → Файл → «Добавить в Dock».

> Данные разных устройств не синхронизируются (так задумано ради приватности). Для переноса используйте Настройки → Экспорт / Импорт.
> Делайте резервную копию время от времени: при удалении приложения с экрана «Домой» iOS удаляет и его данные.

## Разработка
```
python -m http.server 8080     # локальный сервер → http://localhost:8080
node --test tests/*.test.js    # тесты логики, аналитики и шифрования
python tools/make_icons.py     # перегенерировать иконки
```
Сборка не нужна — чистые ES-модули. При изменении файлов увеличьте `VERSION` в `sw.js`.
